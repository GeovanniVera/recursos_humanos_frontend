entregó cada historia de usuario, no como está hoy.

**No se actualizan.** Su contenido técnico vivo se absorbió en `docs/modulos/`. Se
conservan por dos razones: guardan las decisiones y el porqué de ciertas formas del
código, y sostienen la evidencia visual de las entregas.

Si encontrás aquí una afirmación que contradice el código, la documentación
autoritativa es `docs/modulos/`. No edites el histórico para "corregirlo".
